# Public release boundary

Repository này chỉ chứa source code, contract 76 REQ, template, tài liệu vận hành và test source có thể tái lập.

Không thuộc bản public:

- tracker và dữ liệu stress test VN-ALL;
- report HTML, screenshot, evidence ledger đã sinh và API cache;
- thư trao đổi nội bộ, prompt điều phối model và hồ sơ nghiệm thu nội bộ;
- incident archive, bản backup source và lịch sử Git của workspace private;
- credential, auth state hoặc dữ liệu người dùng.
